# Guided Armory Save and Continue 405 Fix — V90

## Root cause

Playbook Builder mutations returned through `back()`. On the shared-hosting request path, the referrer could resolve to the POST/PUT-only mutation endpoint. The browser then followed that location with GET, and Laravel correctly returned 405 Method Not Allowed.

Absolute form actions also risked losing their HTTP method during an HTTP-to-HTTPS redirect.

## Resolution

- Add, update, and remove step actions redirect explicitly to the Interactive Playbook Builder.
- Add, update, and remove response-branch actions redirect explicitly to the same builder.
- Playbook and guided-session write forms now use relative URLs generated by Laravel.
- Submit buttons explicitly use `type="submit"`.
- Guided-session Continue/Use Response returns explicitly to the session page.

No migration or frontend asset build is required.
