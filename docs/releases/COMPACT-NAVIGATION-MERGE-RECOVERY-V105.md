# V105 — Compact Navigation Merge Recovery

The Website Chats update introduced its new Communication destination but also restored the former single-column sidebar. V105 merges the new destination into VVR's compact two-column workspace launcher.

The navigation remains permission-aware and retains controlled overflow only as an accessibility fallback for unusually short displays, enlarged browser text, and high zoom levels. On standard desktop and laptop screens, every available workspace remains visible without routine sidebar scrolling.

No database migration is required.
