# Calendar workspace update

This release activates Calendar with a responsive month grid, county and event-type filters, upcoming auctions, auction CRUD, property linking, and a property-page scheduling shortcut.

Auction records support parcel number, auction type, date, time, secure auction link, property address, six allowlisted counties, private max bid, and notes. Parcel normalization, duplicate protection, financial permissions, HTTPS validation, audit logging, factories, seeders, and automated tests are included.
