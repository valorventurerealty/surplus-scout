# Surplus multi-contact associations v53

Each Surplus case can now be linked to multiple existing Contacts while retaining one authoritative primary claimant.

Supported relationships are claimant, relative, heir, personal representative, attorney, and other. Optional relationship notes can preserve skip-trace context and mailing guidance. The case page lists all associated people and provides controls for authorized users to add and remove links.

The primary claimant is automatically linked and cannot be removed from the association panel. To replace the claimant, edit the case; the prior claimant remains linked as Other so history is not silently discarded. Existing cases are backfilled during migration.

Contact linking is permission-controlled and audit logged. Surplus search also matches any associated person's first or last name.
