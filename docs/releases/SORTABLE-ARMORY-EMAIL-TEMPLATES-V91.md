# Sortable Armory Email Templates — V91

The Armory Email Template Library now supports ascending and descending sorting for:

- Template
- Category
- Subject
- Version
- Status
- Updated

Search, category, and status filters remain applied when a user changes sorting or moves between pages. Category and status sorting follow VVR's configured business order rather than raw alphabetical database values. Sort columns and directions are server allowlisted.

No migration or frontend asset build is required.
